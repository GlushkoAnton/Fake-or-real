Fake or Real: The Impostor Hunt in Texts - Решение
Обзор
Этот проект представляет собой решение для соревнования Kaggle "Fake or Real: The Impostor Hunt in Texts". Задача заключается в классификации пар текстов (file1 и file2), чтобы определить, какой из них является "реальным" (оригинальным), а какой — "фейковым" (сгенерированным или изменённым языковой моделью). Решение использует парный подход к классификации с применением текстовых эмбеддингов, ручных признаков, TF-IDF и ансамбля моделей машинного обучения (XGBoost, CatBoost, LightGBM) с настройкой гиперпараметров и блендингом для достижения высокой точности.
Особенност

Предобработка данных:
Очистка текста: удаление пунктуации (кроме точек), цифр (в зависимости от контекста) и приведение к нижнему регистру.


Инжиниринг признаков:
Текстовые эмбеддинги с использованием SentenceTransformer (intfloat/multilingual-e5-small).
TF-IDF для захвата частотных паттернов слов.
Ручные признаки: длина текста, количество слов, доля уникальных слов, энтропия текста.
Парные признаки: косинусное сходство и евклидово расстояние между эмбеддингами текстов пары.


Моделирование:
Бинарная классификация пар (1, если file1 реальный, 0, если file2 реальный).
Ансамбль из XGBoost, CatBoost и LightGBM с ранней остановкой.
Настройка гиперпараметров с помощью Optuna.
Блендинг out-of-fold (OOF) предсказаний для финальной подачи.


Оценка: 5-кратная стратифицированная кросс-валидация для оценки производительности моделей.
Вывод: Создаётся файл submission_blended.csv с предсказаниями (real_text_id = 1 или 2).

Установка

Склонируйте репозиторий или загрузите код.
Установите зависимости:pip install -r requirements.txt


Убедитесь, что у вас есть датасет из соревнования Kaggle:
train.csv: Содержит id и real_text_id (1 или 2).
train/: Папка с подпапками, содержащими file_1.txt и file_2.txt.
test/: Папка с парами тестовых текстов.



Использование

Разместите файлы датасета в соответствующей структуре директорий (например, /kaggle/input/fake-or-real-the-impostor-hunt/data/).
Запустите основной скрипт:python main.py


Скрипт выполнит:
Загрузку и предобработку данных.
Извлечение эмбеддингов, TF-IDF и ручных признаков.
Настройку гиперпараметров для XGBoost с помощью Optuna.
Обучение и оценку моделей (XGBoost, CatBoost, LightGBM) с использованием 5-кратной кросс-валидации.
Генерацию блендированных предсказаний и сохранение их в submission_blended.csv.

Основные функции

read_data(data_path): Читает пары текстов из директорий в DataFrame.
clean_text(text): Удаляет пунктуацию (кроме точек), цифры (в зависимости от контекста) и приводит текст к нижнему регистру.
extract_handcrafted_features(texts): Вычисляет длину текста, количество слов, долю уникальных слов и энтропию.
prepare_pair_data(df, embedding_model, tfidf_vectorizer): Объединяет эмбеддинги, TF-IDF и парные признаки (косинусное сходство, евклидово расстояние).
tune_model_with_optuna(model_class, X, y, params_base): Настраивает гиперпараметры модели с помощью Optuna.
cross_val_skf(model, X_train, y_train): Выполняет стратифицированную k-кратную кросс-валидацию.
oof_prediction(model, X_train, y_train, X_test): Генерирует out-of-fold предсказания для блендинга.
blend_predictions(oof_dict): Комбинирует предсказания от нескольких моделей с использованием взвешенного усреднения.

Примечания

Производительность: Решение нацелено на достижение лидерборд-скора ~0.85–0.92 (топ-10% на Kaggle) благодаря парным признакам и блендингу. Для повышения скора:
Используйте intfloat/multilingual-e5-large для более качественных эмбеддингов.
Добавьте стэкинг с мета-моделью (например, LogisticRegression).
Настройте гиперпараметры для CatBoost и LightGBM с помощью Optuna.


Использование ресурсов: Скрипт требует много памяти из-за эмбеддингов и TF-IDF. Уменьшите batch_size в get_embeddings, если возникают проблемы с памятью.
Воспроизводимость: Установка RANDOM_STATE = 42 обеспечивает консистентность результатов.
Датасет: Убедитесь, что пути к датасету соответствуют вашей среде (например, /kaggle/input/... для ядер Kaggle).
